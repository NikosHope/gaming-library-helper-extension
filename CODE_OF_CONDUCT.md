# Community conduct

Be respectful, constructive and specific. Critique the proposed change, not the person.
Harassment, threats, discrimination, doxxing and posting another person's private data are unacceptable.

The maintainer may edit or remove abusive content, close disruptive threads, or restrict participation.
Report concerns privately to the repository owner through GitHub; security vulnerabilities should use
[private vulnerability reporting](https://github.com/NikosHope/gaming-library-helper-extension/security/advisories/new).
Do not use public issues to disclose private information.
