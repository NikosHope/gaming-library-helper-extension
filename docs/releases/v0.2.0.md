# Gaming Library Helper 0.2.0

This is an **unsigned Firefox MV3 prerelease**. It is a checked development build, available for
temporary installation through `about:debugging` → This Firefox → Load Temporary Add-on. Extract
the extension ZIP and select `manifest.json`. Firefox removes temporary add-ons after an application
restart. Normal Firefox installation requires Mozilla signing; no signed XPI or AMO listing is
included in this release.

## Changes

- Catalog reconciliation uses verified IGDB/RAWG IDs and explicit human review. Titles alone cannot
  create cross-store ownership or hide a product. Catalog metadata never creates ownership.
- Schema v6 preserves legacy UUID containers, provider IDs, notes, performance records and
  snapshots. The first v5 write retains a local migration backup. Per-product Ignore annotations
  avoid affecting unrelated games in a legacy container.
- Games, Unknown and Technical views show product provenance and official platform observations.
- The optional macOS Native Messaging runner exchanges bounded, validated documents. Its catalog
  credentials stay in Keychain; proposals require revalidation and separate human approval.
- The unused Android ADB dependency tree, including vulnerable node-forge, is removed. The full
  dependency audit passes with zero findings and no exceptions. Firefox Desktop remains supported;
  Android development is unsupported in this checkout.
- Protected version tags produce checked Firefox/source ZIPs, portable SHA-256 checksums and build
  metadata through GitHub Actions. Repository security scans and branch protections remain enabled.

## Verify and install

Download both ZIPs, `SHA256SUMS` and `BUILD_INFO.json` from this release. In the download directory,
run `shasum -a 256 -c SHA256SUMS` (macOS) or `sha256sum -c SHA256SUMS` (Linux). Build metadata records
the exact reviewed source commit and runtime versions. The source ZIP contains fictional tests,
controls and locked dependencies; follow `SOURCE_CODE_REVIEW.md` to reproduce the checks.

The local runner is optional. Install it from a checkout of the release tag and follow
[reconciliation setup](https://github.com/NikosHope/gaming-library-helper-extension/blob/v0.2.0/docs/reconciliation.md). Store ownership capture remains usable without
catalog keys. Products without verified catalog identities stay in Unknown. This is a conservative
identity boundary, not evidence that an account owns no games.

## Acceptance and limitations

Core/adapter/background tests cover migration, backup preservation, product annotations, exact
identity conflicts, malformed native messages, stale snapshots, catalog outages and host failures.
Runner tests use fictional public metadata and fake catalog clients, with no account credentials.
The release workflow repeats all gates, runs a strict full dependency audit, validates archive paths
and CRCs, and reproduces checks from the source ZIP in a clean checkout.

A local Firefox exchange was tested before release, including repeated refresh, disconnect/reconnect,
background restart and host failure recovery. Full live IGDB/RAWG reconciliation still needs the
user's credentials; no complete live catalog acceptance is claimed. A full application restart of a
Mozilla-signed build has not been verified. Automatic reconciliation scheduling is inactive.
Provider-specific restrictions and pending live acceptance are documented in
[library-sync.md](https://github.com/NikosHope/gaming-library-helper-extension/blob/v0.2.0/docs/library-sync.md). Keep personal library backups private.
